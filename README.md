# 棋类游戏合集

一个使用纯HTML、CSS和JavaScript编写的本地双人棋类游戏集合，无需安装任何依赖，直接在浏览器中运行。

## 游戏列表

### 1. 中国象棋
- 标准10×9棋盘
- 完整的棋子走法规则：车、马、炮、象、士、将、兵
- 楚河汉界设计
- 红方先行

### 2. 国际象棋
- 标准8×8棋盘
- 完整的棋子走法规则：王、后、车、象、马、兵
- 经典黑白格子设计
- 白方先行

### 3. 五子棋
- 15×15棋盘
- 五子连珠获胜
- 标准星位标记
- 黑方先行

### 4. 井字棋
- 3×3棋盘
- 三子连线获胜
- 简单易玩
- X先行

### 5. 19×19围棋
- 标准围棋棋盘
- 包含提子规则
- 自动计算提子数
- 禁止自杀手
- 黑方先行

### 6. 9×9围棋
- 小型围棋棋盘
- 适合快速对局
- 规则同19×19围棋
- 黑方先行

## 功能特点

- **悔棋功能**：点击"悔棋"按钮可撤销上一步操作
- **重新开始**：点击"重新开始"按钮可重置当前游戏
- **返回菜单**：随时切换到其他游戏
- **本地双人**：支持两位玩家在同一设备上对战
- **回合提示**：显示当前轮到哪一方
- **胜负判定**：自动检测游戏结果
- **精美界面**：渐变背景和现代化设计
- **响应式布局**：适配不同屏幕尺寸

## 使用方法

1. 打开 `index.html` 文件
2. 在主菜单选择想玩的游戏
3. 点击棋盘进行落子
4. 使用底部按钮控制游戏

### 操作说明

**中国象棋和国际象棋**：
1. 点击要移动的棋子（会高亮显示）
2. 点击目标位置完成移动
3. 只能移动己方棋子

**五子棋、井字棋、围棋**：
1. 直接点击空位落子
2. 轮流下棋直到分出胜负

## 游戏规则要点

### 中国象棋
- 车：直线走任意格，不能越子
- 马：日字走法，可被蹩马腿
- 炮：直线走任意格，吃子需隔一子
- 象：田字走法，不能过河，可被塞象眼
- 士：斜线一格，不能出九宫
- 将：直线一格，不能出九宫
- 兵：未过河只能前进，过河可左右移动

### 国际象棋
- 王：任意方向一格
- 后：直线和斜线任意格
- 车：直线任意格
- 象：斜线任意格
- 马：L型走法
- 兵：前进一格（首步可两格），斜向吃子

### 围棋
- 提子：无气的棋子被提走
- 禁止自杀：不能下没有气的位置（除非能吃对方子）
- 提子计数：显示双方提子数量

## 注意事项

- 游戏仅在浏览器中运行，不需要网络连接
- 建议使用现代浏览器（Chrome、Firefox、Edge等）
- 所有游戏状态仅保存在当前会话中
- 刷新页面会丢失当前游戏进度
